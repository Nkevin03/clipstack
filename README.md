# Clipstack

Gestore della cronologia degli appunti per macOS (13+), veloce e locale, che vive nella menu bar.
Premi **⌘⇧V** ovunque: compare un pannello con tutto ciò che hai copiato (testo, testo formattato,
link, immagini, file, colori, codice), da cercare, filtrare, taggare, fissare, organizzare in Spaces
e incollare nell'app che stavi usando.

Tauri 2 (Rust) + React/TypeScript. Nessuna telemetria, nessuna connessione di rete di default.

## Installazione

1. Apri `Clipstack_0.1.0_universal.dmg` e trascina **Clipstack** in **Applicazioni**.
2. L'app non è firmata con un Developer ID (è firmata "ad-hoc"). Al primo avvio macOS la blocca:
   - **Impostazioni di Sistema → Privacy e sicurezza →** in fondo "Clipstack è stato bloccato…" → **Apri comunque**; oppure
   - da Terminale: `xattr -dr com.apple.quarantine /Applications/Clipstack.app`
3. Avvia Clipstack: compare l'icona nella menu bar e l'onboarding.

### Permesso Accessibilità

Serve per inviare ⌘V all'app in primo piano (incolla automatico).
**Impostazioni di Sistema → Privacy e sicurezza → Accessibilità →** attiva **Clipstack**.
Senza permesso l'elemento viene comunque copiato: premi tu ⌘V.

> Ogni nuova build ad-hoc ha una firma diversa: dopo aver aggiornato l'app potrebbe servire rimuovere
> Clipstack dall'elenco Accessibilità e aggiungerlo di nuovo. In sviluppo (`pnpm tauri dev`) il permesso
> va dato al terminale/IDE da cui lanci il comando.

### Sequenza di copia

1. Premi la scorciatoia (default **⌥⇧⌘C**, modificabile in Impostazioni → Generale → Sequenza di copia), oppure menu bar → *Sequenza di copia*.
2. In alto a destra compare un piccolo pannello: ogni cosa che copi si impila lì in diretta. La riga evidenziata (⌘V) è la prossima che verrà incollata; la **×** su ogni riga la toglie dalla sequenza (resta nella cronologia).
3. In qualsiasi app premi **⌘V** più volte. Opzioni:
   - **Ordine di incolla**: *prima l'ultimo copiato* (tre, due, uno) o *prima il primo copiato* (uno, due, tre);
   - **A ciclo**: gli elementi non vengono consumati e si ricomincia dall'inizio (uno, due, tre, uno, due, tre…).
4. Senza ciclo la sequenza si chiude da sola quando è vuota; altrimenti premi di nuovo la scorciatoia o la ×.

### Finestrella dopo l'incolla

Opzione in Impostazioni → Generale → *Dopo l'incolla*: dopo ogni ⌘V compare per 5 secondi un mini-pannello con gli ultimi
N copiati (N impostabile, default 3). Clicca una riga per incollarla al posto di quella appena incollata.

Entrambe le funzioni richiedono il permesso Accessibilità (per accorgersi dei tuoi ⌘V).

Filtri nella barra di ricerca: `type:image|link|text|rich|file|color|code`, `app:safari`,
`tag:lavoro`, `space:snippets`, `date:today|yesterday|7d|24h|2w`, `pinned:yes|no`
(anche in italiano: `tipo:immagine`, `date:oggi`…).

## Dati e privacy

- Tutto in `~/Library/Application Support/com.clipstack.app/` (SQLite + immagini/miniature). Log in `~/Library/Logs/Clipstack/`.
- Mai salvati: contenuti marcati `org.nspasteboard.ConcealedType`/`TransientType`/`AutoGeneratedType` (password manager) e copie da app escluse (1Password, Bitwarden, Dashlane, LastPass, Enpass, KeePassXC, Accesso Portachiavi, Password già in elenco).
- Dati sensibili (carte valide Luhn, chiavi API, chiavi private, IBAN): non salvare / salva e cancella dopo N minuti (default 10) / salva.
- Cifratura opzionale del database (SQLCipher, chiave nel Portachiavi).
- Unica funzione di rete, opt-in: titolo e icona dei link. L'OCR delle immagini usa Vision, sul dispositivo.
- Esporta/Importa: un `.zip` con `backup.json` e le immagini.

## Sviluppo

Requisiti: Rust stable, Node ≥ 20, pnpm, Xcode Command Line Tools.

```bash
pnpm install
pnpm tauri dev                 # app in sviluppo
pnpm dev → /preview.html       # anteprima UI con backend simulato
pnpm test && pnpm lint && pnpm typecheck
cd src-tauri && cargo test && cargo clippy --all-targets
```

I tipi TypeScript in `src/lib/bindings/` sono generati da Rust (`ts-rs`) eseguendo `cargo test`.
L'icona si rigenera con `cargo run --release --example make_icon -- icons/app-icon-1024.png`
seguito da `pnpm tauri icon src-tauri/icons/app-icon-1024.png`.

### Build di release

```bash
rustup target add x86_64-apple-darwin aarch64-apple-darwin
pnpm tauri build --target universal-apple-darwin
# → src-tauri/target/universal-apple-darwin/release/bundle/macos/Clipstack.app
# → src-tauri/target/universal-apple-darwin/release/bundle/dmg/Clipstack_0.1.0_universal.dmg
```

### Firma Developer ID e notarizzazione (opzionale, per distribuire)

Serve un account Apple Developer (99 €/anno).

1. Crea un certificato **Developer ID Application** e installalo nel Portachiavi.
2. In `src-tauri/tauri.conf.json` imposta `bundle.macOS.signingIdentity` a
   `"Developer ID Application: Nome Cognome (TEAMID)"` (al posto di `"-"`).
3. Esporta le credenziali per la notarizzazione e ricompila:
   ```bash
   export APPLE_ID="tu@example.com"
   export APPLE_PASSWORD="app-specific-password"   # appleid.apple.com → Password per app
   export APPLE_TEAM_ID="TEAMID"
   pnpm tauri build --target universal-apple-darwin
   ```
   Tauri firma con hardened runtime, invia a notarizzazione e allega il ticket (`stapler`).
4. Verifica: `spctl -a -vv /path/Clipstack.app` → `source=Notarized Developer ID`.

Con un Developer ID stabile il permesso Accessibilità resta valido anche dopo gli aggiornamenti.
